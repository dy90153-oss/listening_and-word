# 音律工作室

## Platform
web；可公開索引的一頁式接案網站，手機優先。

## Stack
沿用既有網站的靜態 HTML / CSS / JavaScript 架構，無後端或帳號系統。GitHub 儲存庫內獨立 yinlu-srt 目錄，獨立 Vercel 專案部署。技術與版面由執行者處理。

## Confirmed product truth
使用者已於訪談確認：沿用品牌音律工作室、LINE @818jzowe 與 https://lin.ee/9kHonjI。只接單人國語／華語音檔；重口音或夾雜其他語言先試聽。只交付 UTF-8 SRT 時間軸繁體中文逐字稿，保留原話與語意、補標點斷句，聽不清處標示，不猜補。暫不接英文翻譯、多人對話。

中文每分鐘 NT$15、最低 NT$150，總音檔時長向上進位整分鐘。法律／醫療 +30%；急件 +20%、當日件 +50%、特急件 +100%，加成相加。以試聽後的正式報價為準。

一般預估 3–5 工作天，急件 2–3 工作天，當日件約 8 小時，特急件約 5 小時；每案先確認檔期，完成全額銀行轉帳並確認排單後起算。銀行資訊透過 LINE 私下提供。

交件 7 天內一次免費修正，限漏字、錯字、誤聽；新增翻譯、改寫或格式另議。結案後 7 天內刪除工作室持有的音檔與稿件。

## Audience and primary action
持有單人錄音、獨白、課程或旁白素材，需要可對應時間的繁體中文逐字稿的人。主要行動：加入 LINE 詢價，提供音檔連結、長度、用途與希望交期。

## Brand commitment
清楚、安靜、專業的工作室風格，重點為服務範圍、費用試算、SRT 成品示意與 LINE 詢價。視覺細節已由使用者授權決定，毋須再次選風格。

## Evidence
費率取自使用者指定參考網站及其既有 site.config.js；所有其他商業規則均由訪談確認。沒有客戶推薦、正確率、數量或人工全程處理等佐證，不刊登此類宣稱。範例內容清楚標示格式示意。
